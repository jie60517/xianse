# MMNT · 顯色

MMNT 的網頁版：照片輪播排版，濾鏡換成「顯色」的七款風格（相紙、薄霧、正午、琥珀、燭火、深夜、花期）。
每一款都是先量測這張照片、再補它缺的顏色，不是固定濾鏡。

- 所有運算都在瀏覽器裡完成，照片不會上傳。
- 網頁版限制：作品不會保存在瀏覽器裡；文字圖層與字形挖空在網頁上還畫不出來。

這個資料夾是建置產物，不要手改。原始碼在 MMNT 專案的 `feat/xianse-styles` 分支，建置方式：

```
MMNT_WEB_BASE=/xianse npx expo export --platform web --output-dir dist
```

再把 `dist/` 的內容複製到這裡。
